# Sider2API 简单部署指南

**文件版本**: deno_pro.ts
**更新日期**: 2026-11-03

当前版本要求配置 `AUTH_TOKEN` 才能调用业务接口；未配置时返回 503。仅本地开发可显式设置 `ALLOW_OPEN_AUTH=true`。管理接口使用 `ADMIN_TOKEN`（未设置时回退 `AUTH_TOKEN`），只读看板可使用 `STATS_TOKEN`、`AUTH_TOKEN` 或 `ADMIN_TOKEN`。`/stats` 和 `/stats.json` 默认需要认证，浏览器可在登录页输入凭证；只有显式设置 `STATS_PUBLIC=true` 才公开。

请求体默认上限 32 MiB（`MAX_REQUEST_BODY_BYTES`），会话默认最多 2000 个（`MAX_CONVERSATION_SESSIONS`）。流式响应在首段内容、完成或 20 秒等待窗口到达后提交，窗口内错误使用真实 HTTP 状态及 `Retry-After`；`STREAM_COMMIT_WINDOW_MS=0` 可恢复立即开流。完整变更和验证见 [上游更新移植报告](上游更新移植与验证报告_20261103.md)。
**适用对象**: 希望快速部署 Sider2API 服务的用户

## 1. 本地部署 (推荐入门)

### 适用场景
- 开发和测试
- 个人本地使用
- 快速体验功能

### 部署步骤

#### 步骤 1: 安装 Deno

**Windows (PowerShell)**:
```powershell
irm https://deno.land/install.ps1 | iex
```

**macOS / Linux**:
```bash
curl -fsSL https://deno.land/install.sh | sh
```

#### 步骤 2: 获取 Sider Token

1. 安装 [Sider Chrome 扩展](https://sider.ai/)
2. 打开浏览器开发者工具 (F12)
3. 导航到:**应用程序** → **存储** → **扩展存储** → **Sider:ChatGPT侧边栏**
4. 复制 `token` 字段的值

#### 步骤 3: 下载项目

```bash
git clone https://github.com/goldenhawksu/sider2api.git
cd sider2api
```

#### 步骤 4: 配置环境变量

**Windows (CMD)**:
```cmd
set SIDER_AUTH_TOKEN=你的_Sider_Token
set AUTH_TOKEN=你的_管理密码
```

**Windows (PowerShell)**:
```powershell
$env:SIDER_AUTH_TOKEN="你的_Sider_Token"
$env:AUTH_TOKEN="你的_管理密码"
```

**macOS / Linux**:
```bash
export SIDER_AUTH_TOKEN="你的_Sider_Token"
export AUTH_TOKEN="你的_管理密码"
```

#### 步骤 5: 启动服务

```bash
deno run --allow-net --allow-env --allow-read --allow-write deno_pro.ts
```

**或使用启动脚本 (Windows)**:
```cmd
start_with_auth.bat
```

#### 步骤 6: 验证服务

打开浏览器访问:
- **API 端点**: http://localhost:8000
- **管理界面**: http://localhost:8000/admin
- **模型列表**: http://localhost:8000/v1/models

**测试对话**:
```bash
curl http://localhost:8000/v1/chat/completions \
  -H "Content-Type: application/json" \
  -H "Authorization: Bearer YOUR_AUTH_TOKEN" \
  -d '{
    "model": "claude-4.5-sonnet",
    "messages": [{"role": "user", "content": "你好"}],
    "stream": false
  }'
```

## 2. Deno Deploy 部署 (推荐生产)

### 适用场景
- 生产环境
- 全球边缘网络加速
- 无需服务器维护
- 自动扩容

### 部署步骤

#### 方式一:GitHub 自动部署 (推荐)

**步骤 1**: Fork 项目到你的 GitHub

访问: https://github.com/goldenhawksu/sider2api
点击右上角 **Fork** 按钮

**步骤 2**: 创建 Deno Deploy 项目

1. 访问 https://dash.deno.com/projects
2. 点击 **"New Project"**
3. 选择 **"Deploy from GitHub"**
4. 授权 Deno Deploy 访问你的 GitHub
5. 选择 fork 的仓库 `sider2api`
6. 配置部署:
   - **Entry Point**: `deno_pro.ts`
   - **Branch**: `main`

**步骤 3**: 配置环境变量

在 Deno Deploy 项目设置中添加:

| 变量名 | 值 | 说明 |
|--------|-----|------|
| `SIDER_AUTH_TOKEN` | 你的_Sider_Token | **必需** |
| `AUTH_TOKEN` | 你的_API凭证 | **必需** |
| `ADMIN_TOKEN` | 你的_管理凭证 | 可选，未设置时沿用 AUTH_TOKEN |
| `STATS_TOKEN` | 你的_看板凭证 | 可选，仅用于只读看板 |

**步骤 4**: 部署完成

Deno Deploy 会自动部署,几秒钟后访问分配的域名:
```
https://your-project-name.deno.dev
```

#### 方式二:Playground 快速部署

**步骤 1**: 打开 Playground

访问: https://dash.deno.com/playground

**步骤 2**: 粘贴代码

1. 复制 [deno_pro.ts](../deno_pro.ts) 的全部内容
2. 粘贴到 Playground 编辑器

**步骤 3**: 配置环境变量

点击编辑器左下角 **"Environment Variables"**,添加:
```
SIDER_AUTH_TOKEN=你的_Sider_Token
AUTH_TOKEN=你的_管理密码
```

**步骤 4**: 保存并部署

点击右上角 **"Save & Deploy"**,等待部署完成。

## 3. VPS 部署 (推荐自建)

### 适用场景
- 自有服务器
- 需要完全控制
- 内网部署
- 长期运行

### 部署步骤

#### 快速部署脚本 (Linux)

创建文件 `deploy_sider2api.sh`:

```bash
#!/bin/bash

# 1. 安装 Deno
echo "📦 安装 Deno..."
curl -fsSL https://deno.land/install.sh | sh
export PATH="$HOME/.deno/bin:$PATH"
echo 'export PATH="$HOME/.deno/bin:$PATH"' >> ~/.bashrc

# 2. 创建服务目录
echo "📁 创建服务目录..."
sudo mkdir -p /opt/sider2api
cd /opt/sider2api

# 3. 下载项目
echo "⬇️ 下载项目..."
sudo git clone https://github.com/goldenhawksu/sider2api.git .

# 4. 配置环境变量 (交互式输入)
echo ""
echo "🔑 请输入 Sider Token:"
read -r SIDER_TOKEN
echo ""
echo "🔐 请输入 API 认证凭证 (必填):"
read -r AUTH_TOKEN
[ -n "$AUTH_TOKEN" ] || { echo "必须填写 API 认证凭证"; exit 1; }

# 5. 创建 systemd 服务
echo "⚙️ 创建 systemd 服务..."
sudo tee /etc/systemd/system/sider2api.service > /dev/null <<EOF
[Unit]
Description=Sider2API Service
After=network.target

[Service]
Type=simple
User=$USER
WorkingDirectory=/opt/sider2api
Environment=SIDER_AUTH_TOKEN=$SIDER_TOKEN
$([ -n "$AUTH_TOKEN" ] && echo "Environment=AUTH_TOKEN=$AUTH_TOKEN")
Environment=PORT=8000
ExecStart=$HOME/.deno/bin/deno run --allow-net --allow-env --allow-read --allow-write deno_pro.ts
Restart=always
RestartSec=10

[Install]
WantedBy=multi-user.target
EOF

# 6. 启动服务
echo "🚀 启动服务..."
sudo systemctl daemon-reload
sudo systemctl enable sider2api
sudo systemctl start sider2api

echo ""
echo "✅ 部署完成!"
echo ""
echo "服务状态: sudo systemctl status sider2api"
echo "查看日志: sudo journalctl -u sider2api -f"
echo "访问地址: http://$(curl -s ifconfig.me):8000"
```

#### 使用脚本部署

```bash
# 1. 创建并运行脚本
chmod +x deploy_sider2api.sh
./deploy_sider2api.sh

# 2. 验证服务
sudo systemctl status sider2api

# 3. 查看日志
sudo journalctl -u sider2api -f
```

#### 服务管理命令

```bash
# 启动服务
sudo systemctl start sider2api

# 停止服务
sudo systemctl stop sider2api

# 重启服务
sudo systemctl restart sider2api

# 查看状态
sudo systemctl status sider2api

# 查看日志
sudo journalctl -u sider2api -f

# 开机自启
sudo systemctl enable sider2api
```

## 4. Docker 部署 (推荐容器化)

### 适用场景
- 容器化环境
- 微服务架构
- 需要快速迁移
- 多实例部署

### 部署步骤

#### 步骤 1: 创建 Dockerfile

在项目根目录创建 `Dockerfile`:

```dockerfile
FROM denoland/deno:alpine

WORKDIR /app

# 复制代码
COPY deno_pro.ts .
COPY custom_models.json .
COPY admin.html .

# 暴露端口
EXPOSE 8000

# 启动服务
CMD ["run", "--allow-net", "--allow-env", "--allow-read", "--allow-write", "deno_pro.ts"]
```

#### 步骤 2: 构建镜像

```bash
docker build -t sider2api:latest .
```

#### 步骤 3: 运行容器

```bash
docker run -d \
  --name sider2api \
  -p 8000:8000 \
  -e SIDER_AUTH_TOKEN="你的_Sider_Token" \
  -e AUTH_TOKEN="你的_管理密码" \
  --restart unless-stopped \
  sider2api:latest
```

#### 步骤 4: 使用 Docker Compose (推荐)

创建 `docker-compose.yml`:

```yaml
version: '3.8'

services:
  sider2api:
    image: sider2api:latest
    build:
      context: .
      dockerfile: Dockerfile
    container_name: sider2api
    ports:
      - "8000:8000"
    environment:
      - SIDER_AUTH_TOKEN=${SIDER_AUTH_TOKEN}
      - AUTH_TOKEN=${AUTH_TOKEN}
    restart: unless-stopped
    volumes:
      - ./custom_models.json:/app/custom_models.json
```

创建 `.env` 文件:
```env
SIDER_AUTH_TOKEN=你的_Sider_Token
AUTH_TOKEN=你的_管理密码
```

启动服务:
```bash
docker-compose up -d
```

#### Docker 管理命令

```bash
# 查看日志
docker logs -f sider2api

# 停止服务
docker stop sider2api

# 启动服务
docker start sider2api

# 重启服务
docker restart sider2api

# 删除容器
docker rm -f sider2api

# 使用 docker-compose
docker-compose up -d      # 启动
docker-compose down       # 停止
docker-compose logs -f    # 查看日志
```

## 5. 常见问题

### Q1: 如何获取 Sider Token?

**答**:
1. 安装 [Sider Chrome 扩展](https://sider.ai/)
2. F12 打开开发者工具
3. **应用程序** → **存储** → **扩展存储** → **Sider:ChatGPT侧边栏**
4. 复制 `token` 字段值

### Q2: AUTH_TOKEN 是什么?

**答**: 调用业务 API 的凭证，生产环境必须配置。管理界面使用 `ADMIN_TOKEN`；未单独设置时沿用 `AUTH_TOKEN`。管理 API 支持 Bearer Token 或 `x-api-key`。未配置认证时默认拒绝请求，本地开发须显式设置 `ALLOW_OPEN_AUTH=true` 才开放。

### Q3: 如何测试服务是否正常?

**答**: 运行以下命令:
```bash
# 测试模型列表
curl http://localhost:8000/v1/models

# 测试对话
curl http://localhost:8000/v1/chat/completions \
  -H "Content-Type: application/json" \
  -H "Authorization: Bearer YOUR_AUTH_TOKEN" \
  -d '{
    "model": "claude-4.5-sonnet",
    "messages": [{"role": "user", "content": "你好"}]
  }'
```

### Q4: 端口 8000 被占用怎么办?

**答**: 配置 `PORT` 环境变量:
```bash
# Linux/macOS
export PORT=3000
deno run --allow-net --allow-env --allow-read --allow-write deno_pro.ts

# Windows CMD
set PORT=3000
deno run --allow-net --allow-env --allow-read --allow-write deno_pro.ts
```

### Q5: 如何配置 HTTPS?

**答**:
- **Deno Deploy**: 自动提供 HTTPS
- **本地/VPS**: 使用 Nginx 反向代理:

```nginx
server {
    listen 443 ssl http2;
    server_name your-domain.com;

    ssl_certificate /path/to/cert.pem;
    ssl_certificate_key /path/to/key.pem;

    location / {
        proxy_pass http://localhost:8000;
        proxy_set_header Host $host;
        proxy_set_header X-Real-IP $remote_addr;
        proxy_set_header X-Forwarded-For $proxy_add_x_forwarded_for;
        proxy_set_header X-Forwarded-Proto $scheme;
    }
}
```

### Q6: 支持哪些模型?

**答**: 支持 29+ 模型,包括:
- GPT: gpt-4.1, gpt-4o, gpt-4.1-mini
- Claude: claude-4.5-sonnet, claude-4.1-opus, claude-haiku-4.5
- Gemini: gemini-2.5-pro, gemini-2.5-flash
- DeepSeek: deepseek-v3.1, deepseek-reasoner

完整列表访问: http://localhost:8000/v1/models

### Q7: 如何添加自定义模型?

**答**:
1. 访问管理界面: http://localhost:8000/admin
2. 输入 ADMIN_TOKEN；未单独设置时输入 AUTH_TOKEN
3. 在 "添加自定义模型" 区域:
   - **模型 ID**: 自定义名称(如 my-gpt)
   - **Sider 模型**: 选择底层模型(如 gpt-4o)
   - **描述**: 模型说明
4. 点击 "添加模型"

### Q8: 如何升级到最新版本?

**答**:

**Git 部署**:
```bash
cd sider2api
git pull origin main
# 重启服务 (systemd)
sudo systemctl restart sider2api
# 或 Docker
docker-compose down && docker-compose up -d --build
```

**Deno Deploy**:
- 推送到 GitHub,自动部署

**Playground**:
- 复制最新代码重新部署

### Q9: 性能如何优化?

**答**:
1. **使用 Deno Deploy**: 全球边缘节点自动优化
2. **启用 HTTPS**: 提升安全性和速度
3. **使用 CDN**: 加速静态资源
4. **配置缓存**: Nginx 反向代理缓存
5. **监控资源**: 使用 `htop` 监控 VPS 资源

### Q10: 日志在哪里查看?

**答**:

**本地运行**: 直接在终端查看输出

**systemd 服务**:
```bash
sudo journalctl -u sider2api -f
```

**Docker**:
```bash
docker logs -f sider2api
```

**Deno Deploy**: 在项目的 Logs 页面查看
