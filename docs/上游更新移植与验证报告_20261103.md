## 配置与兼容性

- `AUTH_TOKEN`：业务调用凭证，未配置默认拒绝；仅本地开发可设 `ALLOW_OPEN_AUTH=true`。
- `ADMIN_TOKEN`：管理 API 凭证；未设置时沿用 `AUTH_TOKEN`。
- `STATS_TOKEN`：只读看板凭证；看板同时接受客户端和管理凭证。`STATS_PUBLIC=true` 显式恢复公开。
- `MAX_REQUEST_BODY_BYTES`：默认 33554432，按 UTF-8 实际字节限制，超限返回 413。
- `MAX_CONVERSATION_SESSIONS`：默认 2000；已有一小时过期规则继续有效。
- `STREAM_COMMIT_WINDOW_MS`：默认 20000；设为 0 立即提交流，正数窗口内的 ping 与协议起始事件先缓冲。
- 已提交 SSE 的错误新增可选 `retry_after` 秒数字段；HTTP 错误继续通过 `Retry-After` 头表达。
- 原 `totals` 结构保留，统计快照新增 `upstream` 字段。新计数只能从新版本开始积累，不能回填历史。
